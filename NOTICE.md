# Sources and licenses

- **Quran text**: Tanzil Project (tanzil.net), used verbatim, via github.com/fawazahmed0/quran-api (edition `ara-qurankhaledhosn`, by Khaled Hosny; `ara-quransimple` for search). Page/juz/sajda data from the same project. Tanzil terms: the text may be copied and redistributed verbatim with a link to tanzil.net.
- **Tafsir** (11 books, fetched per surah on the phone on request): github.com/spa5k/tafsir_api (MIT), texts from quran.com and Tarteel QUL. Not redistributed by this project.
- **Recitation audio** (streamed on request): everyayah.com.
- **Hadith, bundled** (al-Nawawi's Forty, Forty Qudsi): github.com/fawazahmed0/hadith-api (public domain / Unlicense).
- **Hadith, downloaded in the app on request**: github.com/AhmedBaset/hadith-json (Arabic text and Arabic chapter names). Not redistributed by this project; each phone fetches the book from the source.
- **Fonts** (SIL Open Font License 1.1, from github.com/google/fonts): Amiri and Amiri Quran (Khaled Hosny), Tajawal, Reem Kufi, El Messiri, Changa.
- **Adhkar texts** (Content.kt): Hisn al-Muslim wording, typed without diacritics.
- **Explained hadith** (fetched on request): HadeethEnc.com API (hadeethenc.com/api).
- **Islamic books** (fetched on request): IslamHouse.com API; the books are theirs and are downloaded from their servers.
